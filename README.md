# Léa Spagnuolo — Portfolio

## Files
- `index.html`: portfolio structure
- `styles.css`: visual design and responsive styles (V132 mobile Hero refinement)
- `app.js`: rendering, editable text/media, and carousel logic
- `CV_Lea_Spagnuolo.pdf`: downloadable CV
- `Media/`: keep the existing original photo/video files here in the GitHub repository

## Publish on GitHub Pages
Upload the contents of this package to the repository root and replace the matching files. Keep the existing case-sensitive `Media/` folder in the repository unchanged; the original media assets are not included in this package.

## Validation
`app.js` passes Node's syntax checker. The V132 change is CSS-only and limited to phone widths (520px and below); desktop/tablet styling is left unchanged. Please check the live page on an actual phone after publishing, as a full browser-device visual test was not available here.
